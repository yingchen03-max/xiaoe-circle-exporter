# 小鹅通助手

一个 Manifest V3 Chrome 扩展和油猴脚本，用来把小鹅通鹅圈子帖子的正文、附件、一级评论、回复评论和评论媒体导出为 Markdown 文档或 HTML 离线压缩包。

## 功能特性

- **两种导出格式**：点击"打包下载"后可选择
  - **Markdown 文档（.md）**：仅正文与评论，单文件直接保存，适合笔记归档
  - **HTML 离线包（.zip）**：含附件、图片、音频和视频，可离线完整阅读
- **问答帖完整导出**：作者以"回答提问"形式发布的帖子，会把提问者的问题（提问者昵称、问题标题、问题正文）以引用块形式渲染在作者回答之前，不再丢失问题上下文
- **回复上下文**：评论的回复中若回复的是另一条回复，会标注"回复 @被回复者"；被回复的评论已被删除或不可见时，会附加提示
- **完整分页抓取**：分页读取全部一级评论，并为每条一级评论继续分页读取全部回复；任一附件或媒体下载失败时会停止导出并报错，避免生成看似成功但内容不完整的压缩包

## 导出内容

### Markdown 格式（.md 单文件）

- 帖子元信息（社群、作者、时间、来源链接）
- 问答帖的问题引用块（如有）
- 正文、附件目录和完整评论树
- 图片、音频等媒体以原始 URL 引用

### HTML 离线包（.zip）

- `标题.html`：离线阅读版，可直接用浏览器打开
- `post.json`：结构化帖子与评论数据
- `files/`：帖子附件
- `media/`：帖子及评论里的图片、音频和视频

### 文件命名

导出文件统一命名为 `时间_标题_作者.扩展名`，例如 `2026-07-07_093200_概念与个股_胡浩.md`（标题取前 5 个字）。

帖子标题的选取顺序：API 返回的帖子标题 → 问答帖的问题标题 → 正文第一行（截断至 40 字）→ `帖子-{id}`。

## 扩展安装

```bash
npm install
npm run build
```

然后打开 `chrome://extensions`：

1. 开启右上角"开发者模式"。
2. 点击"加载已解压的扩展程序"。
3. 选择本项目的 `dist/` 目录。

## 油猴脚本安装

```bash
npm install
npm run build:userscript
```

生成文件是 `dist/xiaoe-helper.user.js`。在 Tampermonkey 或 Violentmonkey 中安装这个脚本后，登录并打开 `https://quanzi.xiaoe-tech.com/`，帖子列表和帖子详情页都会显示"打包下载"按钮。

油猴版通过 `GM_xmlhttpRequest` 下载附件和评论媒体，压缩包仍然在浏览器本地生成；脚本元信息里已声明小鹅通和常见静态资源域名的 `@connect` 权限。油猴版目前仅支持 HTML 离线包（.zip）格式。

## 使用

1. 登录并打开鹅圈子。
2. 在帖子列表中点击目标帖子右下方的"打包下载"，在弹出的菜单中选择导出格式；扩展版也可以进入帖子详情页后，从扩展弹窗中选择格式并点击"打包当前帖子"。
3. 等待浏览器开始下载文件。

## 隐私

- 数据和压缩包全部在浏览器本地处理，不会上传到任何服务器。
- 导出内容保留页面可见的作者、时间和 IP 属地，但会排除接口中的精确 IP、内部用户 ID、企业账号标识等隐藏字段。
- 扩展只申请鹅圈子和小鹅通常用静态资源域名的访问权限，不申请 `<all_urls>`。
